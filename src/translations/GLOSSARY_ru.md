# Глоссарий перевода RoastArtisan (EN → RU)

Согласованная терминология для `artisan_ru.ts`. При правке перевода держаться этих
вариантов, чтобы термины были единообразны по всему интерфейсу.

Домен: программа визуального контроля обжарки кофе. Базовое правило — это **кофе
(зёрна)**, а не еда: «roast» = «обжарка», а не «жаркое/жарить».

## События обжарки

| EN | RU | Аббревиатура / примечание |
|----|----|----|
| Charge | Загрузка | засыпка зелёного зерна в барабан |
| Drop | Выгрузка | выгрузка готового зерна |
| Turning Point / TP | Точка разворота | ТР |
| Dry End | Пожелтение | момент окончания фазы сушки |
| First Crack | Первый крэк | ПК (начало/конец: ПКн / ПКк) |
| Second Crack | Второй крэк | ВК (начало/конец: ВКн / ВКк) |
| Crack | крэк | жаргон ростеров |
| Cool / Cooling | Охлаждение | |
| Reset | Сброс / Сбросить | не путать с Drop = Выгрузка |

## Стиль

- Обращение к пользователю — на «вы» (строчное).
- Капитализация элементов интерфейса — первое слово с заглавной
  («Цвет обжарки», «Конец сушки»), даже если в оригинале ВЕРХНИЙ регистр.
- Жаргон-транслитерация допустима там, где её использует сообщество:
  Каппинг, Типпинг, Скорчинг, Батч, Ростер, крэк.
- Буква «ё» пишется (зёрна, зелёное).
